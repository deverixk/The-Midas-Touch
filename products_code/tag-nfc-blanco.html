Tag NFC Adhesivo (Blanco)

Etiqueta adhesiva ultradelgada con tecnología NFC. Versátil y discreta, perfecta para cualquier superficie. Ideal para automatización del hogar, regalos personalizados, menús digitales, información de productos y más. Pequeña pero poderosa.

Características

  • Material: Etiqueta adhesiva laminada de alta durabilidad
  • Acabado: Blanco
  • Chip NFC: NTAG213 (144 bytes)
  • Frecuencia: 13.56 MHz — ISO 14443-A / NFC Type 2
  • Compatibilidad: iPhone y Android
  • Reprogramable más de 100,000 veces
  • Resistente al agua y al desgaste
  • Fácil instalación gracias a su adhesivo fuerte
